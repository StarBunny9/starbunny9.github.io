Project Description

Party wizard is a game development project for my software architecture course at school. The goal of this project is to learn more about software architecture. The focus was mostly on making decoupled, scalable systems using design patterns such as OOP principles, strategy pattern, model view presenter, Observer, Event Bus, ScriptableObjects, Finite State Machine and command patterns, Many of which are present in this project! Additionally, I did code reviews and Unit Tests for this project and made a UML class diagram to communicate my design choices to the course teacher. I very much enjoyed making this, and I love to see how easy implementing new features like enemies and spells is after putting some time into creating a proper system for them.

Everything in this project has been made by myself, including all the sprites, art and sounds.
