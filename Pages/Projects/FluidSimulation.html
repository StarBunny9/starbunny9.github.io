Project Description

This is a personal university project where I attempted to make an SPH (Smoothed Particle Hydrodynamics) simulation. It is mostly based on this paper (Müller, Charypar & Gross, 2003) and Sebastian Lague's implementation in unity. Except I tried to make this in C++ and OpenGL to generalise it and learn more on how it could connect to an engine on it's own. Besides learning how to make a fluid simulation, the goal of this project was also to do a benchmark and analysis on optimisations. In this case I learned how to write an OpenGL compute shader containing all the simulation math and handle communication between the CPU and GPU. The benchmark clearly confirmed a reduction in time complexity of O ( n2 ) to O ( n ) when using the compute shaders, without any major error points or weird behaviour.

Please check out this project's GitHub Wiki for details about the implementation, benchmarks, tests, analysis and research.

Reflection

I am really proud of the result, and it's almost exactly as I had hoped it would be. Playing around with the fluid is really satisfying and has probably distracted me for multiple hours during the development.

Seeing the particles behave more and more like a real fluid with every iteration was very rewarding, and this has definitely thought me that perseverance and trusting the process are key to finishing a project.

I was also surprised that compute shaders are not as scary as I had thought and this definitely opened the door for me to use it in future projects as well.

Gathering data and doing data analysis felt very familiar since I have done lots of experiments when I was studying Applied Physics that required me to create a goal/hypothesis, write methods, do error estimation, data collection, calculations, analysis, and finally a discussion and conclusion.
